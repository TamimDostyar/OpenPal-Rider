# OpenPal System Documentation

High-level system documentation for OpenPal, based on the backend repository in this workspace. This focuses on architecture, data flow, configuration, and deployment. Client apps and infrastructure outside this repo are documented as external or unknown where details are not available.

## Contents

- architecture.md - System architecture overview and key flows
- api-summary.md - REST API surface summary
- deployment.md - Runtime configuration and deployment topology
- diagrams/system-context.mmd - Mermaid system context diagram
- diagrams/system-context.puml - PlantUML system context diagram
- diagrams/backend-components.mmd - Mermaid backend component diagram
- diagrams/backend-components.puml - PlantUML backend component diagram

## Scope

- Backend service in this repo is authoritative.
- Non-backend components are included at a high level and marked as external/unknown when not documented here.
